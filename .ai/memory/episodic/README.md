# Episodic Memory

"What happened, and when?" Session logs, meeting capture, incident
timelines. Write freely — this folder is meant to be high-volume and cheap.

- Default `trust: unverified`. Never cite an episodic note as justification
  for a decision; promote the relevant fact to `../semantic/` first.
- Default `review_after`: 14-30 days out. Past that date, treat the note as
  stale raw material, not as current context.
- Template: `../templates/episodic.md`.

See `mem-2026-08-13-template-bootstrap.md` for a worked example.
