# Procedural Memory

"How do we do this?" Runbooks and checklists for repeatable multi-step
tasks.

- A procedural note is a **draft skill**. Once it has been followed
  successfully several times without correction, promote it to
  `.ai/skills/<name>/SKILL.md` (see `.ai/SKILL-FORMAT.md`) and record the
  promotion in the note's `## Graduation Criteria` section.
- Template: `../templates/procedural.md`.

See `mem-2026-08-13-write-a-memory-note.md` for a worked example.
