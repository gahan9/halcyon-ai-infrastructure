# Prospective Memory

"What must happen next?" Backlog items, roadmap milestones, and time- or
event-triggered reminders.

- `backlog.md` and `roadmap.md` are structured tables, not individual notes —
  see `../GOVERNANCE.md` for their format and the optional GitHub Issues
  sync.
- Individual prospective notes (one per non-trivial item) use
  `../templates/prospective.md` and are linked from the relevant backlog row.
- Template: `../templates/prospective.md`.

- `backlog.md` — local work backlog; see `.ai/memory/GOVERNANCE.md` for the
  optional GitHub Issues mirror.
- `roadmap.md` — milestone table with a confidence column maintained by the
  `roadmap-review` skill (`.ai/skills/roadmap-review/SKILL.md`).
