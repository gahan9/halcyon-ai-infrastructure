# Semantic Memory

"What is true?" Decisions (ADR-style), facts, glossary entries, and hub
notes (a "Map of Content" tying a topic's notes together).

- A note only counts as reliable once `trust` is `reviewed` or
  `authoritative` — set at PR-merge time by a human reviewer, per
  `../GOVERNANCE.md`.
- `status` follows the public MADR/ADR vocabulary: `draft`, `proposed`,
  `accepted`, `deprecated`, `superseded`.
- Template: `../templates/semantic.md`.

See `mem-2026-08-13-memory-primitive-adopted.md` for a worked example.
